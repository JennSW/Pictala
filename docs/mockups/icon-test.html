Camera / list icon test

Testing the two commercially-licensed icons Jen dropped in this folder (Camera2.png, list.png) against the eBird-logo replacement question from issue #48: camera = has a Flickr photo, list/notebook = logged on eBird. Rough test page, not wired into the real app.

1. Legibility at badge size

The open question from #48 was whether a notebook-style icon still reads clearly at small badge scale (the wellness-app reference used a small icon badge lower-left on thumbnails). Both icons shown here from 40px down to 14px.

2. Corner badges on photo cards

Same thumbnail-left photo-card layout as outing-grouping-mockup.html (DESIGN.md §10.3), with camera/list swapped in as corner badges instead of the inline 🐦 emoji. Two badges stacked side by side is the proposed way to show "on both eBird and Flickr" without needing a single icon to carry both meanings.

3. Inline-prefix variant (drop-in swap for the current 🐦 emoji)

Alternative placement: icon inline before the label text, matching how the "on eBird" bird-icon prefix already works in the outing-grouping mockup, instead of a corner badge on the thumbnail.

4. Icon color vs. brand palette

Flagging for awareness, not necessarily a problem since these are fixed-color licensed stock icons: Camera2.png's lavender is close to #D19FFF, and list.png's peach is close to #FFC7A7 — both are colors explicitly not carried forward for BirdTrip per the confirmed direction in DESIGN.md §10.4. Shown here on white, navy-tint, and periwinkle-tint to see how they sit against the palette that was kept.
